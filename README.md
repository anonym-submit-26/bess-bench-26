# BESS-Bench

> A benchmark for spectral representation learning and temporal forecasting on
> 35 years of citizen-science stellar spectroscopy.

**Submission to NeurIPS 2026 Evaluations & Datasets Track** (anonymized for
double-blind review).

---

## What is in this repository?

| Path | Purpose |
|------|---------|
| `scripts/` | **Reproduction entry points.** `reproduce_paper_seed42.sh` (single-command reviewer path), `compare_with_reference.py` (diff vs `reference_results/`), and `cluster/` (SLURM scripts + `run_all.sh` for the full multi-seed pipeline). See *Quick reproduction* below. |
| `data/embeddings_halpha/` | Pre-computed Hα embeddings (`star_data.pt`, ~15 MB) for the three downstream tasks (SpecProbe, LineTransfer, EWForecast). Regenerated by `scripts/cluster/00_pretrain_encoder.slurm`. |
| `stage1_encoder/` | BeMAE: masked-autoencoder Hα spectral encoder. **803 K-parameter encoder** (the published baseline used for downstream tasks); 912 K total parameters when counting the training-time decoder. R² = 0.93 on held-out stars. |
| `downstream/` | Baselined tasks: SpecProbe Hα single-line probes (multi-seed), LineTransfer Hβ→Hα cross-line, EWForecast horizon forecasting with PCA+Ridge and zero-shot Chronos-Bolt / TimesFM. Phase classification is deferred to v1.1. |
| `figures/` | Figures used in the paper. |
| `stats/` | Scripts for bootstrap confidence intervals, multi-seed aggregation, LaTeX tables, and paper figures. |
| `paper/` | Paper artefacts: figures (`figures/`), tables (`tables/`), figure scripts (`figure_scripts/`) and validation scripts (`scripts/`). |
| `dataset/DATASHEET.md` | Datasheet for the BESS-Bench dataset (Gebru et al. template). |

## Dataset access

The BESS-Bench dataset is hosted on HuggingFace:

> **https://huggingface.co/datasets/anonym-submit-26/bess-bench-26** *(anonymous mirror; will be replaced by the authors' permanent repository at camera-ready)*

```python
from datasets import load_dataset
ds = load_dataset("anonym-submit-26/bess-bench-26", split="train")
```

## Pretrained encoder

The BeMAE-Hα encoder checkpoint (seed 42, ≈803 K parameters, 3 MB) used to
produce every paper number is published on HuggingFace as a separate model
repository:

> **https://huggingface.co/anonym-submit-26/bemae-halpha-v1** *(anonymous mirror)*

```python
from huggingface_hub import snapshot_download
local = snapshot_download("anonym-submit-26/bemae-halpha-v1")
```

A model card with the architecture, training recipe, intended use and known
limitations is bundled at `stage1_encoder/hf_export/bemae-halpha-v1/README.md`.
The single-command reviewer reproduction script downloads it automatically;
see *Quick reproduction* below.

Key facts:
- 339 115 parquet rows = 37 624 physical observations of 1 468 Be stars
- 35 years of observations (1990–2025)
- 91.6 % of observations from amateur astronomers (81.7 % of rows); 4.6 % of observations professional
- Train / val / test split **by star** (no temporal leakage)
- Licence: **CC-BY-4.0**

## Quick reproduction

Two complementary paths are documented in [REPRODUCE.md](REPRODUCE.md):

**Path A — Quick verification (recommended for reviewers).** A single
script reproduces every headline number for `seed=42` from the public
HuggingFace artefacts and runs `compare_with_reference.py` automatically:

```bash
pip install -r requirements.txt
bash scripts/reproduce_paper_seed42.sh
```

Wall-clock: ~25 min on 1 GPU (RTX 2080 Ti, matches the reference run) or
~3 h on CPU fallback. Outputs land under `results_reproduced/`; logs in
`results_reproduced/logs/`.

**Path B — Full pipeline (cluster).** Encoder pretraining for 3 seeds,
ablation grid, multi-seed aggregation and bootstrap CIs are driven by a
master SLURM launcher:

```bash
cd scripts/cluster && bash run_all.sh
```

Wall-clock: ~3 h end-to-end on a SLURM cluster (1 GPU + 8 CPU); ~22 GPU-h
total compute. Phase logs in `scripts/cluster/logs/`.

See [REPRODUCE.md](REPRODUCE.md) for the per-phase walk-through, the
141-metric tolerance audit (STRICT / GPU-OK), and step-by-step output
descriptions.
